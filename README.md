\# Restaurant Table Reservation System



A web-based Restaurant Table Reservation System that allows customers to reserve a table by entering their details, reservation date, time, and number of guests.



\## Features



\- Table reservation

\- Customer details

\- Reservation date and time

\- Number of guests

\- Phone number collection

\- Store reservations in MongoDB

\- Frontend connected to backend API

\- Delete reservations through API



\## Technologies Used



\### Frontend

\- HTML

\- CSS

\- JavaScript



\### Backend

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- CORS
